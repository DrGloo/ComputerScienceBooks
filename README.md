# Computer Science Books

A curated collection of foundational and advanced computer science textbooks covering core disciplines — from algorithms and data structures to networking, operating systems, and software engineering.

Whether you're a student building fundamentals or a developer brushing up on theory, this library is designed to give you direct access to high-quality references across the CS curriculum.

> **Didn't find what you need?** Open an [issue](../../issues) to request a book and it will be added.

---

## What's Inside

### Algorithms & Data Structures

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **The Algorithm Design Manual** | Steven Skiena | Practical algorithm design with real-world war stories. One of the best bridges between theory and application. |
| **Algorithms** | (Classic Reference) | A comprehensive treatment of fundamental algorithms and data structures. |
| **Cracking the Coding Interview** | Gayle Laakmann McDowell | The industry-standard guide for technical interview preparation — covers patterns, not just problems. |

### Programming Languages

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **Java: The Complete Reference** (9th Ed.) | Herbert Schildt | Encyclopedic Java reference covering the language, libraries, and ecosystem end to end. |
| **OCA/OCP Java SE 7 Study Guide** | Sierra & Bates | Certification-focused but excellent for deeply understanding Java semantics and gotchas. |
| **Head First Python** (2nd Ed.) | Paul Barry | Visual, beginner-friendly Python introduction using the Head First pedagogical approach. |
| **Let Us C** | Yashavant Kanetkar | A classic entry point into C programming, widely used in Indian university curricula. |

### Web Technologies

| Book | Why It Matters |
|------|----------------|
| **CSS** | Core reference for styling and layout on the web. |

### Databases

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **Database System Concepts** (6th Ed.) | Silberschatz, Korth & Sudarshan | The gold-standard academic textbook on relational databases, transactions, and query processing. |
| **Database Systems** | Navathe | Comprehensive coverage of database design, ER modeling, normalization, and SQL. |
| **Fundamentals of Data Engineering** | Reis & Housley | A modern take on the data engineering lifecycle — pipelines, storage, orchestration, and more. |

### Networking & Systems

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **Computer Networking and the Internet** (5th Ed.) | Douglas Comer | Covers networking from physical layer to application protocols with clarity and depth. |
| **Operating Systems** (6th Ed.) | William Stallings | Thorough treatment of process management, memory, file systems, and security in modern OSes. |
| **System Programming** | — | Low-level systems programming concepts — essential for understanding how software meets hardware. |
| **Professional Assembly Language** | Richard Blum | Practical guide to x86 assembly — invaluable for understanding what compilers actually produce. |

### Software Engineering & Design

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **Software Engineering** | Ian Sommerville | One of the most widely used SE textbooks — covers requirements, design, testing, and project management. |
| **Software Engineering: A Practitioner's Approach** | Roger Pressman | Process-oriented SE reference with strong coverage of agile, quality assurance, and software metrics. |
| **Object-Oriented Software Engineering** | Bernd Bruegge & Allen Dutoit | Focuses on OO analysis and design with UML, use cases, and real project case studies. |
| **The Art of Readable Code** | Boswell & Foucher | Short, opinionated, and incredibly practical — teaches you to write code that other humans can actually understand. |
| **The Pragmatic Programmer** | David Thomas & Andrew Hunt | The definitive guide to thinking like a professional developer — DRY, automation, debugging, and habits that separate good code from great. |

### Theory of Computation & Formal Languages

| Book | Author(s) | Why It Matters |
|------|-----------|----------------|
| **Introduction to Computer Theory** | Daniel Cohen | Accessible introduction to automata, formal languages, and computability. |
| **Theory of Computation** | Peter Linz | Covers finite automata, context-free grammars, Turing machines, and undecidability with mathematical rigor. |

## Suggested Reading Paths

**Just starting out in CS?**
> `Let Us C` | `Head First Python` | `The Pragmatic Programmer` | `Cracking the Coding Interview` | `The Art of Readable Code`

**Preparing for systems-level work?**
> `Operating Systems (Stallings)` | `System Programming` | `Professional Assembly Language`

**Focused on backend / data?**
> `Database System Concepts` | `Fundamentals of Data Engineering` | `Computer Networking`

**Going deep on theory?**
> `Introduction to Computer Theory (Cohen)` | `Theory of Computation (Linz)` | `Algorithm Design Manual`
